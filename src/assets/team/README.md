# Team photos

Drop a photo here named after the member and their card shows it instead of their initials.
The site crops it to a circle and resizes it at build time, so any reasonably sized square-ish headshot works.

- Format: `.jpg`, `.jpeg`, `.png` or `.webp`
- Name: the member's name in lowercase, accents removed, spaces as hyphens (e.g. `carter-cameron.jpg`)
- Only add a photo with that person's OK to show it on the site.
